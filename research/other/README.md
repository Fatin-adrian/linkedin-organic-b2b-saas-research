# Other Sources

Articles, newsletters, slide decks, threads, and miscellaneous references that support the research but are not LinkedIn posts or video transcripts.

## Purpose

Centralize written long-form material — blog posts, Substack essays, conference slides, PDFs — with clear attribution.

## Capture template

```markdown
# Source note

- **Title:**
- **Author / expert:** [Name — link to sources.md row if applicable]
- **Source URL:**
- **Type:** article | newsletter | deck | thread | PDF | other
- **Published:** YYYY-MM-DD
- **Captured:** YYYY-MM-DD

## Summary

## Relevant excerpts

> "..."

## LinkedIn organic strategy notes

- applicable tactics:
- B2B SaaS context:
- limitations / caveats:

## Research tags

- themes:
- patterns:
- cross-links: [paths to related files in this repo]
```

## Naming convention

`{author-slug}_{YYYY-MM-DD}_{short-title}.md`

## File types

- Prefer `.md` notes with links and excerpts.
- Store binary files (PDF, PPTX) alongside a matching `.md` index file with metadata and summary.
