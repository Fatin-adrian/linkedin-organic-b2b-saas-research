# LinkedIn Evidence Notes

Curated LinkedIn evidence notes from the approved expert roster in `../sources.md`.

## Purpose

Store representative LinkedIn evidence for later analysis of format, hooks, CTAs, content themes, and playbook usefulness.

## Current folder contents

This folder contains one concise evidence note per approved expert. These notes are not full post transcripts or full strategic analysis yet.

## Optional capture template

Create one file per post (or per expert batch) using this structure:

```markdown
# Post capture

- **Expert:** [Name - link to sources.md row]
- **Source URL:** [LinkedIn post URL]
- **Captured:** YYYY-MM-DD
- **Format:** text | carousel | video | poll | document | other
- **Topic / pillar:**
- **Hook (first line or slide):**
- **Structure notes:**
- **CTA:**
- **Engagement signals (if visible):** impressions / reactions / comments - optional
- **Takeaways for playbook:**

## Content

[Full text if available, or structured summary if manual curation only]

## Research tags

- themes:
- patterns:
- open questions:
```

## Naming convention

`{expert-slug}.md`

## Manual curation note

LinkedIn may restrict automated export. Summaries are acceptable when full text cannot be saved - always include URL and capture date.
